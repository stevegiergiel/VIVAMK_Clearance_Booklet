# VIVAMK Clearance Booklet

This repository contains the Steve & Jus Christmas Clearance booklet project and a web/iframe version for publishing on a website.

## Iframe catalogue

The responsive web catalogue is generated by:

- `vivamk_clearance_iframe.py`
- `iframe_config.json`

It reads the live Christmas clearance page:

`https://stevegiergiel.vivamknetwork.co.uk/clearance/christmas-sale.html`

Products without a usable image are excluded. Each published product has a **BUY ME** button linking directly to its VivaMK product page.

## GitHub Pages

The workflow `.github/workflows/deploy-pages.yml` rebuilds and publishes the catalogue automatically when the iframe generator, config, or workflow changes. It can also be run manually from the GitHub **Actions** tab.

Expected public address:

`https://stevegiergiel.github.io/VIVAMK_Clearance_Booklet/`

## Embed on your website

Use this iframe in an HTML embed block:

```html
<iframe
  src="https://stevegiergiel.github.io/VIVAMK_Clearance_Booklet/"
  title="Steve & Jus Christmas Clearance Specials"
  width="100%"
  height="1100"
  style="border:0;width:100%;max-width:100%;"
  loading="lazy">
</iframe>
```

If your website builder supports responsive HTML, you can increase or reduce the height to suit the page.

## Updating settings

Edit `iframe_config.json` to change contact details, the opportunity link/phone number, catalogue URL, description length or other publishing settings without editing the Python source.
