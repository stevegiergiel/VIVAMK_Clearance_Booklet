# VIVAMK Christmas Clearance - v1.05 preferred design

Canonical filename: `vivamk_clearance_christmas.py`

Run:
`pip install -r requirements.txt`
`python vivamk_clearance_christmas.py`

Design lock:
- Complete holly sprigs are taken directly from `preferred_booklet_style_reference.png`.
- No stretched, truncated or improvised holly.
- Dark-green/gold banner footer on booklet pages.
- Any required 4-page booklet padding is rendered as designed Christmas/order pages, not blank pages.
- `opportunity_back_cover.png` is the exact physical final page.
- Six products per A5 product page.
- Products without usable images are omitted.
